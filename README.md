var, let, const difference: var function-scoped, let block-scoped and changeable, const block-scoped but cannot be reassigned.

Spread operator: It expands elements of an array or object into individual values.

map vs filter vs forEach: map() returns a new transformed array, filter() returns a new filtered array, forEach() just loops without returning a new array.

Arrow function: A shorter ES6 syntax for writing functions using =>.

Template literals: ES6 strings using backticks ` ` that allow variable interpolation like ${name}.
